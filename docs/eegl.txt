//// ideas
//////////
d<space> - delete all the spaces until another character.
"dot" should repeat the last used macro, not the last action from it.
A command-line option to open the program only if the file exists.
Just like there are text objects to select or copy text, there should be to replace text.
   As in, "ri(" = "replace insides of parens with what's in the register"
A command to get the highlight group under the cursor 
A command to generate a UUID (v7 by default, v4 if passed an argument)
If we start searching and find something but add another letter and now there are not matches, do
   not jump back to the beginning. Stay at the last match there was. This should be an option. 
Simple command to redirect other command's output to the current buffer. (redir?) 
Unmodifiable flag on the portal too. For immutable views into data, like JSON pretty viewers
When selected in linewise mode, "a," to add a comma to every line, `s"` to surround every line 
   with quotes
For commands that open a temp portal like `:reg`, `:ls`, make exclamation variants that append
   lines after cursor instead
Option to set max file size where syntax higlighting is on by default
Options for cursor shapes (one for insert mode, one for other modes)
