   a general way to create auto-updateable views of buffers?

[ ] Transition to pure 256-color palette and removal of double-width symbols
[ ] Replace VimScript with Wren

[ ] @errorformat is unsuitable for an option: it should be per-filetype. We need a new event type

   Then when they are saved with .txt, .json, .yaml or without file extension, they stay that way.
   But if they are saved with another extension, they get isCode = true and the IsCodeChange fires.
   The existing @errorformat should be repurposed as a global option that the autocommand can 
   choose to use. But we need separate commands to set the errorformat property for a book, also 
   to set isCode.
